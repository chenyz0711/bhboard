# bhboard - a lightweight message board for brothers

A simple, password-protected message board for close friends. Built with vanilla HTML/CSS/JS and Redis.

## Features

- User registration & login (email + password)
- Post messages with username
- Auto-refresh
- Mobile-friendly

## Tech Stack

- Frontend: Vanilla HTML/CSS/JS
- Database: Upstash Redis
- Hosting: Vercel
